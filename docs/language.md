# 対応している言語仕様

現在の Metalic は、式の構文解析と、小さな関数モジュールの名前・型検査までを実装しています。ソースの評価やコード生成は行いません。

## 式モード

整数、識別子、文字列、四則演算、単項の符号、括弧を扱います。複数の式は `;` で区切り、末尾の `;` は省略できます。

```text
1 + 2 * 3;
-(alpha + 42);
"hello Metal";
```

二項演算は左結合で、乗除が加減より優先します。単項の `+`／`-` は右結合です。式モードでは識別子の名前解決・型検査を行わず、構文として結果に残します。

整数は十進 u32 です。識別子の先頭は ASCII の英字かアンダースコアで、2文字目以降は数字も使えます。文字列は UTF-8 と escaped byte を保持しますが、文字列内容の評価は行いません。escape されていない文字列内改行は拒否します。

`//` の行コメントと、入れ子を許さない `/* */` コメントに対応しています。空の式プログラムはエラーです。

## モジュールモード

`--module` を指定すると、引数と戻り値の型を明示した関数を宣言できます。型は `u32` と `str`、本体は一つの式です。

```text
fn add(x: u32, y: u32): u32 { x + y }
fn identity(text: str): str { text }
fn greeting(): str { "こんにちは" }
```

各関数は独立した引数スコープを持ちます。関数名・同じ関数内の引数名の重複、未定義の引数参照、数値演算への `str`、宣言した戻り値型との不一致を拒否します。`fn` はモジュールモードだけの予約語です。

## 現在の上限と未対応機能

| 項目 | 上限・状態 |
|---|---|
| 1入力のサイズ | UTF-8で1 MiBまで |
| モジュール内の関数 | 256まで |
| 一関数の引数 | 64まで |
| 診断・spanの位置 | 文字数ではなく UTF-8 byte offset |
| 関数呼出し、`let`、分岐 | 未実装 |
| 型推論、依存型、affine 使用検査 | 未実装 |
| プログラムの実行、コード生成 | 未実装 |

診断がある場合、未検証の構文木は返しません。構文・名前・型の順で検査し、最初の診断を返します。複数エラーからの回復処理はありません。
